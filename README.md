# Мониторинг ресурсов

Скрипт каждые 5 секунд записывает в `monitor.log` сведения о памяти, файловых системах и нагрузке.
Он работает в Docker вместе с HTTP-сервером Python. Nginx предоставляет доступ к журналу по HTTPS.

## Запуск

Нужна отдельная VM с Ubuntu 22.04, systemd, доступом к интернету и правами `sudo`.
Из каталога проекта выполните:

```bash
sudo bash bootstrap.sh
```

Скрипт устанавливает зависимости, готовит хранилище, собирает контейнер и включает службы.
При повторном запуске существующие данные сохраняются.

## Проверка и управление

```bash
curl -kI https://127.0.0.1/
curl -k https://127.0.0.1/monitor.log
sudo systemctl status my-app --no-pager
sudo systemctl restart my-app
sudo journalctl -u my-app -n 20 --no-pager
```

Сертификат самоподписанный; `-k` отключает его проверку.
Порт контейнера 8080 доступен только через `127.0.0.1`; внешние запросы принимает Nginx.

## Файлы проекта

- `script.sh` - сбор показателей ресурсов.
- `Dockerfile`, `entrypoint.sh` - образ и управление процессами контейнера.
- `docker-compose.yml` - контейнер, порт и подключение данных.
- `bootstrap.sh` - развёртывание приложения.
- `scripts/storage.sh` - подготовка и восстановление RAID/LVM.
- `deploy/` - конфигурация Nginx и службы systemd.

RAID 1 смонтирован в `/mnt/raid`, независимый LVM-том - в `/mnt/logs`.
Данные приложения находятся в `/mnt/logs/my-app` и доступны контейнеру как `/var/www`.
При загрузке VM служба `capstone-storage` восстанавливает хранилище перед запуском приложения.
